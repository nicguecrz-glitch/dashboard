
# Dashboard del Clima

Dashboard interactivo del clima desarrollado con React, TypeScript y Material UI (MUI).

El objetivo del proyecto es presentar información meteorológica de forma clara, organizada y responsiva, utilizando datos proporcionados por la API de Open-Meteo.

El dashboard permitirá visualizar la temperatura actual, la humedad, las condiciones del cielo, la evolución de la temperatura por hora y el pronóstico de los próximos días.
